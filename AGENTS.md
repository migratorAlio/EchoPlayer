## Architecture

### Single playback pipeline (mpv render API)
- `MpvWidget` (QOpenGLWidget) owns `mpv_handle` + `mpv_render_context`
- `initializeGL()` creates the render context with `MPV_RENDER_PARAM_API_TYPE_OPENGL`,
  plus the native display (`MPV_RENDER_PARAM_X11_DISPLAY` / `MPV_RENDER_PARAM_WL_DISPLAY`)
  so VAAPI/EGL zero-copy hardware decode works on both X11 and Wayland
- `paintGL()` calls `mpv_render_context_render()` into the default framebuffer;
  `mpv_render_context_set_update_callback()` drives widget `update()`
- **No `--wid`, no X11 child window, no xcb passive grabs.** Works on X11 and Wayland
- mpv owns BOTH audio and video. There is no `--audio=no` and no SDL audio device.
  Hardware decode backends are switched by setting the `hwdec` property (no reload).

### AudioEngine (FFmpeg, analysis only)
- Opens the same local file independently but never outputs sound
- Supplies duration, audio codec name, embedded cover art, and LRC lyrics
  (UTF-8 / GB18030 / Big5 / Shift-JIS auto-detected)
- Decodes audio into a bounded S16 stereo 48 kHz PCM ring buffer. A 30 ms timer drains
  it and runs FFT → `spectrumReady`. Ring backpressure keeps the visualizer near realtime.
- Only started for audio-only local files; videos and network streams skip it entirely
- **There is no A/V sync code**: mpv outputs the sound itself, so no drift is possible

### Fine-tuning panel (`AdjustPanel`)
- Non-modal QDialog, three tabs: audio / subtitles / picture. Opened with `Ctrl+P`
  or the Tools menu; all values persist under `QSettings` `adjust/*`.
- Audio: 10-band EQ (±12 dB, 31 Hz … 16 kHz), 4 presets, `dynaudnorm` normalization,
  `balance`, `audio-delay`. Builds one `lavfi=[...]` filter graph and is the **single
  owner of mpv's `af` property** — the right-click presets and `E` shortcut call
  `applyPreset()` instead of writing `af` themselves.
- Subtitles: `sub-scale`, `sub-delay`, `sub-pos`, `sub-font`, `sub-bold`, `sub-italic`,
  `sub-align-x`, `sub-border-size/color`, `sub-shadow-offset/color`, `sub-blur` and
  three `QColorDialog` pickers (`sub-color` / `sub-border-color` / `sub-shadow-color`).
- Picture: `brightness` / `contrast` / `saturation` / `gamma` / `hue` video equalizer.
- `applyAll()` is called from `MainWindow::applyPersistedPlayback()` on every
  `fileLoaded`, so settings survive a file change. `bumpBrightness()` /
  `bumpSubScale()` / `bumpSubDelay()` / `resetVideo()` back the existing shortcuts
  and menu items; MainWindow no longer keeps duplicate brightness/subtitle state.
- `retranslateUi()` follows `LanguageManager::languageChanged` (all static labels
  are created without text and filled in that one function).

### Desktop integration (`src/core`, `src/ui`)
- `MprisController`: registers `org.mpris.MediaPlayer2.EchoPlayer` at
  `/org/mpris/MediaPlayer2` with two `QDBusAbstractAdaptor`s (root + Player).
  Exports status, metadata (incl. `mpris:artUrl` for lock-screen cover), volume,
  position, rate, loop/shuffle; implements Play/Pause/Next/Previous/Seek/
  SetPosition/OpenUri/Raise/Quit. Property changes are sent as explicit
  `PropertiesChanged` messages; seeking also emits the `Seeked` signal.
- `ScreenSaverInhibitor`: async `Inhibit()`/`UnInhibit()` on freedesktop / GNOME /
  KDE screen-saver services, tied to play/pause. Degrades silently if none exists.
- `QSystemTrayIcon`: show/hide, transport, screenshot, quit. Closing the window can
  minimize to tray (configurable, default on); tray "Quit" sets `m_forceQuit` so
  `closeEvent()` really exits.
- `ThumbnailProvider`: FFmpeg decodes keyframes in `QThreadPool`, quantized to
  5-second buckets with an LRU-ish cache; `MainWindow` shows a hover preview over
  the seek bar. Streams show the time label only, no decode.
- Embedded cover art is exported to `CacheLocation/cover-<md5>.jpg` for MPRIS.

### Internationalization
- `TsTranslator` (in `i18n/languagemanager.cpp`) reads `.ts` XML directly — no
  `lrelease`. `LanguageManager::switchLanguage()` installs it and emits
  `languageChanged`.
- `src/i18n/echoPlayer_{zh_CN,zh_TW,en}.ts` are generated by
  `tools/update_translations.py`: it scans every `tr()` (and explicit
  `QCoreApplication::translate`), maps files to QTranslator contexts, and fails
  on any string missing an English translation. 192 strings / 5 contexts.
- `MainWindow::captureTranslatables()` records the original source text on every
  context-menu and tray action; `retranslateDynamic()` re-translates them via
  `QCoreApplication::translate()` on `QEvent::LanguageChange`, so menus do not
  keep stale labels. `TitleBar`, `ControlBar`, `AdjustPanel` and `PlaylistApp`
  implement `retranslateUi()` + `changeEvent()` themselves.
- The playlist is a separate process: `PlaylistProtocol::makeLanguage()` forwards
  locale changes, `PlaylistApp::handleLine()` applies them, and
  `src/playlist/main.cpp` reads the same `QSettings` so it starts in the right
  language before the first message arrives.

### Playback flow
1. `MainWindow::openMedia(path)` → for local files AudioEngine opens for metadata,
   for network URLs it is skipped (avoids blocking on network probes); mpv `loadfile`
2. mpv `fileLoaded` → apply persisted settings (volume, speed, hwdec, brightness,
   subtitle scale), restore last playback position, start spectrum analysis,
   populate audio/subtitle track menus from mpv `track-list`, publish MPRIS metadata
3. mpv `playbackFinished` (EOF) → repeat-one restarts the file, otherwise
   `nextPlaylistIndex()` (sequential / shuffle / playlist loop) picks the next entry
4. Position / duration / pause all come from mpv property observations; MPRIS
   status and screen-saver inhibition follow `pausedChanged`

### Persistence & playlist
- `QSettings` stores geometry, volume, speed, hwdec, language, recent files,
  per-file resume positions, repeat/shuffle mode, tray preference, the playlist
  itself (in manual mode) and all `adjust/*` values
- Single instance via `QLocalServer`; a second launch forwards all file paths
  (multiple files are appended to the playlist)
- Drag & drop: media files open (several → appended), subtitle files use `sub-add`;
  non-local URLs are accepted as streams
- Playlist is a separate process (`EchoPlayer-playlist`) over a tab-separated
  line protocol: player→ `PLAYLIST` / `CURRENT` / `GEOMETRY` / `MODE` / `LANG`;
  app→ `CMD ADD|REMOVE|MOVE|CLEAR|MODE|PLAY`. Manual mode is entered on any edit
  and stops the automatic same-directory scan. `src/ui/playlistpanel.*` is legacy
  dead code, intentionally not compiled.

## Build & Run
- `cmake -B build -DCMAKE_BUILD_TYPE=Debug && cmake --build build -j$(nproc)`
- `./build.sh run [file]`
- Depends on: Qt6 (Core Gui Widgets OpenGLWidgets Network DBus), FFmpeg
  (avformat avcodec avutil swscale swresample), mpv (>= 0.34). SDL2 and xcb are
  no longer required.
- Installs `org.echoplayer.EchoPlayer.desktop` + `.metainfo.xml`,
  `org.echoplayer.EchoPlayer.png`, AppStream metadata and three `.ts` catalogs.

## Packaging
- deb / AppImage: verified paths (CPack + `packaging/make-appimage.sh`).
- Flatpak: `packaging/flatpak/org.echoplayer.EchoPlayer.json` (JSON so it can be
  machine-checked). KDE 6.8 Platform/SDK + ffmpeg-full extension; builds mpv
  v0.36.0 as libmpv with `-Dlibplacebo=disabled` to avoid the libplacebo/Vulkan
  dependency chain. `validate.py` checks 29 invariants including every meson
  option against mpv v0.36.0's real `meson_options.txt`; `build.sh` runs it,
  calls `flatpak-builder --show-manifest`, checks runtimes/SDK deps, then builds.
- **A real Flatpak build has not been run here** (flatpak/flatpak-builder are
  missing and installing them needs a password). deb / AppImage / native builds
  are verified.

## Key bindings
`Space`/`K` play-pause · `←`/`→` ±5s · `Shift+←/→` ±30s · `↑`/`↓` volume ·
`M` mute · `F`/`Enter` fullscreen · `Esc` exit fullscreen · `[`/`]` speed ·
`Backspace` 1.0x · `,`/`.` frame step · `S` screenshot · `PgUp`/`PgDn` prev/next file ·
`Z`/`X` subtitle delay · `A` AB loop · `I` media info · `1`-`4` aspect ratio ·
`R` rotate · `B`/`N` brightness · `E` audio preset · `L` cycle repeat ·
`H` hide to tray · `Ctrl+O` open file · `Ctrl+U` open network stream ·
`Ctrl+P` fine-tuning panel · `Ctrl+R` toggle shuffle · `Ctrl+Q` quit.

## Remaining gaps
- Flatpak: static validation passes (29/29), but no sandbox build was possible
  on this machine. `libass`/`libpulse` availability in the KDE SDK is checked at
  build time by `build.sh`.
- No full media library, no scrub storyboard (one frame per 5-second bucket),
  no per-subtitle ASS style editor beyond the exposed mpv properties.
- MPRIS `TrackList` interface is intentionally not implemented (playlist lives
  in a separate process).
